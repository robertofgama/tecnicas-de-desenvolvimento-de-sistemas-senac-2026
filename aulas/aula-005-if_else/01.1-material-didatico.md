# Aula 5 — if e else

Sem nenhum desvio, o programa roda de cima pra baixo, linha por linha. Com `if` ele passa a **decidir**: "se isso for verdade, faça aquilo".

---
## 1. if: só se for verdade

```js
const estoque = 0

if (estoque === 0) {
  console.log("Produto esgotado")
}

console.log("Fim")
```


---

Anatomia:

- `if` + uma **condição** entre parênteses. Condição é qualquer coisa que dê `true` ou `false` (comparações como `estoque === 0` ou `total > 1000`).
- Um **bloco** entre chaves `{ }`: só roda se a condição for `true`.
- O que vem depois do bloco roda de qualquer jeito.

Troque `estoque` pra `5` e rode de novo: "Produto esgotado" some, "Fim" continua.

---

## 2. else: senão

```js
const estoque = 5

if (estoque === 0) {
  console.log("Produto esgotado")
} else {
  console.log("Pode vender")
}
```

Um dos dois blocos **sempre** roda. Nunca os dois, nunca nenhum.

---

## 3. else if: mais de dois caminhos

```js
const qtd = 50

if (qtd >= 50) {
  console.log("Desconto de 20%")
} else if (qtd >= 10) {
  console.log("Desconto de 10%")
} else {
  console.log("Sem desconto")
}
```

O JS testa de cima pra baixo e **para no primeiro `true`**. Por isso a ordem importa: se o `qtd >= 10` viesse primeiro, 50 unidades cairiam ali e nunca chegariam nos 20%. Regra prática: do mais específico pro mais geral.

O `else` do final é opcional: é o "nenhum dos anteriores".

---

## 4. Condições compostas

Tudo da aula de operadores entra aqui:

```js
const estoque = 4
const pagamentoAprovado = true

if (estoque > 0 && pagamentoAprovado) {
  console.log("Entrega liberada")
} else if (estoque > 0) {
  console.log("Aguardando pagamento")   // se chegou aqui, tem estoque; o que falta é o pagamento
} else {
  console.log("Sem estoque")
}
```

---

## 5. if dentro de if

Dá pra aninhar, mas cada nível a mais deixa o código mais difícil de ler. Dois níveis, ok. Três, pense se `&&` ou `else if` não resolve.

```js
const cliente = "Agro Silva"
const valor = 12000

if (valor > 10000) {
  if (cliente === "Agro Silva") {
    console.log("Pedido grande de cliente antigo: ligar pra agradecer")
  } else {
    console.log("Pedido grande: aprovar com o gerente")
  }
}
```

---

## 6. Verdadeiro "mais ou menos": truthy e falsy

O JS aceita qualquer valor como condição, não só `true` e `false`. Ele converte. Contam como **falso**:

`false`, `0`, `""` (texto vazio), `null`, `undefined`, `NaN`

**Todo o resto é verdadeiro**, inclusive `"0"`, `"false"` e `-1`.

```js
const nomeCliente = ""

if (nomeCliente) {
  console.log("Cliente:", nomeCliente)
} else {
  console.log("Cliente não informado")   // texto vazio é falsy
}
```

É prático pra testar "tem valor?", mas cuidado: `if (qtd)` com `qtd = 0` cai no else, e 0 pode ser um valor válido.

---

## 7. Erros clássicos

| Código | Problema |
|---|---|
| `if (status = "aberto")` | Um `=` só **atribui**. A condição vira `"aberto"`, que é truthy: entra sempre. Use `===`. |
| `if (qtd > 0);` | O ponto e vírgula fecha o if ali. O bloco seguinte roda sempre. |
| `if (qtd > 0) console.log("a"); console.log("b")` | Sem chaves, só a **primeira** instrução pertence ao if. Use chaves sempre. |
| `if (qtd >= 10 && <= 50)` | `SyntaxError`: cada lado do `&&` precisa ser uma comparação completa: `qtd >= 10 && qtd <= 50`. |

---

## 8. Bônus: operador ternário

Um if/else de uma linha, pra quando a decisão é só "qual valor usar":

```js
const estoque = 5
const situacao = estoque > 0 ? "disponível" : "esgotado"
console.log(situacao)   // disponível
```

Lê-se: "estoque maior que zero **?** então `"disponível"` **:** senão `"esgotado"`". Você vai ver isso o tempo todo em React. Pra lógica maior que isso, if/else normal.

---

## Cola rápida

- `if (condição) { }` → roda se for `true`.
- `else { }` → senão. `else if (outra) { }` → outro caminho. Para no primeiro `true`.
- Ordem: do mais específico pro mais geral.
- Falsy: `false`, `0`, `""`, `null`, `undefined`, `NaN`. O resto é truthy.
- `=` atribui, `===` compara. Chaves sempre.
- Ternário: `condição ? seVerdadeiro : seFalso`.

## Exercícios

1. **Par ou ímpar.** Com `const numero = 7`, imprima `7 é ímpar`. Troque pra 8 e rode de novo. Dica: `%`.

2. **Faixa de desconto.** Com `preco = 180` e `quantidade`, calcule o total com desconto: 20% a partir de 50 unidades, 10% a partir de 10, nada abaixo disso. Teste com 5, 10 e 50 (os totais devem dar 900, 1620 e 7200).

3. **Validação da quantidade.** Antes de salvar um item, valide `quantidade` contra `estoque = 20`:
   - menor ou igual a 0 → `Quantidade inválida`
   - maior que o estoque → `Só temos 20 em estoque` (o número vem da variável)
   - senão → `Item adicionado`

   Teste com -3, 500 e 2.

4. **Status do pedido.** Com `const status = "enviado"`, imprima a mensagem certa pro cliente:
   - `"rascunho"` → `Pedido ainda não enviado`
   - `"enviado"` → `Pedido recebido, aguardando faturamento`
   - `"faturado"` → `Nota fiscal emitida`
   - `"entregue"` → `Pedido concluído`
   - qualquer outra coisa → `Status desconhecido: xxx`, mostrando o status

5. **Frete grátis.** O frete é grátis se o total do pedido for de R$ 5.000 ou mais **ou** se o cliente for do RS. Senão, custa R$ 150. Com `total` e `uf`, use o **ternário** pra decidir o valor do frete e imprima o total final. Teste as quatro combinações (total alto ou baixo, RS ou outro estado).

6. **Da nota pra menção.** O curso usa menções A, B, C e D. Invente uma régua: 9 ou mais → `A`, de 7 a 8,9 → `B`, de 5 a 6,9 → `C`, abaixo de 5 → `D`. Se a nota for menor que 0 ou maior que 10, imprima `Nota inválida`. Teste com 9.5, 7, 4.9 e 11.
