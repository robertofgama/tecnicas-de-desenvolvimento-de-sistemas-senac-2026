# Aula 4 — Operadores

Variável guarda. Operador **faz alguma coisa** com o que está guardado: soma, compara, combina. São três famílias.

## 1. Aritméticos: fazer conta

| Operador | Nome | Exemplo | Resultado |
|---|---|---|---|
| `+` | soma | `180 + 20` | `200` |
| `-` | subtração | `180 - 20` | `160` |
| `*` | multiplicação | `180 * 2` | `360` |
| `/` | divisão | `180 / 2` | `90` |
| `%` | resto da divisão | `7 % 2` | `1` |
| `**` | potência | `2 ** 3` | `8` |

```js
const preco = 180
const qtd = 10
const total = preco * qtd
console.log(total)   // 1800
```

### O resto (%) é mais útil do que parece

`%` devolve o que **sobra** da divisão inteira.

```js
console.log(10 % 3)   // 1 → 10 = 3 x 3, sobra 1
console.log(8 % 2)    // 0 → dividiu certinho: 8 é par
console.log(7 % 2)    // 1 → sobrou: 7 é ímpar
console.log(50 % 12)  // 2 → 50 discos em caixas de 12: 4 caixas e sobram 2
```

### Ordem das contas

Mesma regra da escola: `*` e `/` antes de `+` e `-`. Parênteses mandam em tudo.

```js
console.log(2 + 3 * 4)     // 14
console.log((2 + 3) * 4)   // 20
```

Na dúvida, use parênteses. Ninguém vai te julgar.

### Atalhos

```js
let estoque = 10
estoque = estoque + 5   // 15
estoque += 5            // 20 → mesma coisa, mais curto
estoque -= 3            // 17
estoque *= 2            // 34
estoque++               // 35 → soma 1
estoque--               // 34 → tira 1
```

### Decimais: o JS é um pouco estranho

```js
console.log(0.1 + 0.2)                // 0.30000000000000004 (sério)
console.log((0.1 + 0.2).toFixed(2))   // "0.30" → arredonda pra 2 casas (vira texto)
```

Acontece em qualquer linguagem que use ponto flutuante, não é só o JS. Pra mostrar dinheiro, `toFixed(2)` resolve.

## 2. O `+` tem dupla personalidade

Com números, soma. Com **texto, junta** (concatena). E basta um dos lados ser texto:

```js
console.log(5 + 5)               // 10
console.log("5" + 5)             // "55"  ← juntou texto
console.log("5" - 5)             // 0     ← o - só sabe fazer conta, então converte
console.log("Total: " + 10 + 5)  // "Total: 105" (resolve da esquerda pra direita)
```

Isso aparece muito quando o valor vem de um formulário, que **sempre** entrega texto. A solução é converter antes:

```js
const digitado = "180"
console.log(Number(digitado) + 20)   // 200
console.log(Number("abc"))           // NaN → "Not a Number": não deu pra converter
```

## 3. Comparação: perguntar

O resultado é sempre um boolean: `true` ou `false`.

| Operador | Pergunta | Exemplo | Resultado |
|---|---|---|---|
| `>` | maior? | `10 > 5` | `true` |
| `<` | menor? | `10 < 5` | `false` |
| `>=` | maior ou igual? | `10 >= 10` | `true` |
| `<=` | menor ou igual? | `9 <= 10` | `true` |
| `===` | igual (valor **e** tipo)? | `10 === 10` | `true` |
| `!==` | diferente? | `10 !== 5` | `true` |

```js
const estoque = 4
const pedido = 10
console.log(pedido <= estoque)   // false → não dá pra atender
```

### `==` e `===`: use sempre três

```js
console.log("5" == 5)    // true  → == converte antes de comparar (perigoso)
console.log("5" === 5)   // false → === compara valor E tipo
```

Com `==`, `"0" == false` dá `true`, `"" == 0` dá `true`... Esquece que `==` existe. Use `===` e `!==` sempre.

Cuidado também: `=` é atribuição ("recebe"), `===` é comparação ("é igual?"). Trocar os dois é o bug clássico.

## 4. Lógicos: combinar perguntas

| Operador | Nome | Verdadeiro quando...                |
| -------- | ---- | ----------------------------------- |
| `&&`     | E    | **os dois** lados são verdadeiros   |
| `\|\|`   | OU   | **pelo menos um** lado é verdadeiro |
| `!`      | NÃO  | inverte: `!true` é `false`          |

```js
const temEstoque = true
const pagamentoAprovado = false

console.log(temEstoque && pagamentoAprovado)   // false → faltou o pagamento
console.log(temEstoque || pagamentoAprovado)   // true  → um já basta
console.log(!temEstoque)                       // false
```

Juntando com comparações:

```js
const qtd = 15
console.log(qtd >= 10 && qtd < 50)   // true → está na faixa de 10 a 49
```

`&&` resolve antes de `||`. Se misturar os dois, use parênteses pra deixar claro:

```js
const estaLogado = true
const ehAdmin = false
const ehDono = true
console.log(estaLogado && (ehAdmin || ehDono))   // true
```

## Cola rápida

- Aritméticos: `+ - * / % **`, atalhos `+= -= ++ --`. Parênteses na dúvida.
- `%` = resto. `x % 2 === 0` → par.
- `+` com texto junta. Converta com `Number()` antes de somar.
- `toFixed(2)` pra mostrar dinheiro.
- Comparação devolve boolean. **Sempre `===` e `!==`.**
- `&&` (e), `||` (ou), `!` (não).

## Exercícios

1. **Calculadora de pedido.** Com `preco = 180`, `qtd = 10` e `frete = 150`, calcule e imprima o subtotal, o desconto de 10% sobre o subtotal e o total (subtotal menos desconto, mais frete). Use `toFixed(2)` no total.

2. **Caixas de discos.** Discos de corte vão em caixas de 12. Com `discos = 50`, imprima quantas caixas fechadas dá pra montar e quantos discos sobram. Dica: `%` dá a sobra; dividindo os que **não** sobraram por 12 você tem as caixas.

3. **Adivinhe antes de rodar.** Escreva num comentário o resultado de cada linha, depois rode:
   ```js
   console.log("10" + 1)
   console.log("10" - 1)
   console.log(10 + 1 + "1")
   console.log("3" * "4")
   console.log(7 % 3)
   console.log(2 ** 10)
   console.log(10 / 4)
   ```

4. **Dois iguais ou três iguais.** Preveja e depois rode:
   ```js
   console.log(180 == "180")
   console.log(180 === "180")
   console.log(0 == false)
   console.log(0 === false)
   console.log("" == 0)
   console.log(null == undefined)
   console.log(null === undefined)
   ```
   Depois escreva num comentário qual dos dois você vai usar daqui pra frente.

5. **Meta do mês.** Com `meta = 250000` e `vendido = 212500`, imprima o percentual atingido (com 1 casa decimal), quanto falta pra bater a meta e um boolean dizendo se já bateu.

6. **Liberar entrega?** Com as variáveis abaixo, imprima um único boolean que diga se a entrega pode sair. A regra: tem estoque suficiente **e** (o pagamento foi aprovado **ou** o cliente tem crédito liberado). Depois troque os valores e veja o resultado mudar.

